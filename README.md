Entry for the [make.fun bounty "Tell a Whole Story in 32 Characters"](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978): one Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a whole story.

## The entry

```
This WiFi Testified Against Me
```

30 characters. The joke: a home Wi-Fi network has taken the witness stand. The story it implies: somebody stood trial, and the evidence that sank them was their own network — the router logs, the late-night searches, the connection history. The reader fills in the crime, the courtroom, and the verdict.

## How it works

`main.py` is a deterministic, standard-library-only Python program. It writes the name to `/output/entry.txt` and validates it against the competition gate first (UTF-8 text, 1 to 32 characters, not only white space).

```sh
python3 main.py
```
